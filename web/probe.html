Device probe build —

Read-only. Probe asks the device what it is, what firmware it runs, which messages it supports, and what is on its +Drive. Listen sends nothing at all — it captures whatever the device chooses to send, so you can trigger a dump from the front panel (SETTINGS > SYSEX DUMP > SYSEX SEND) and save the result as a .syx. Read project asks for all 128 patterns, all 128 sound-pool slots and the project settings, one at a time, waiting for each answer before asking again — the same capture, without touching the device's menus. Requests carry an empty body, so none of that writes anything to the device. Write back is the one exception and the only control here that changes your instrument: it sends a record from the current capture back to the slot it came from — identical bytes to the same place — then reads it again and compares. Load a scratch project first, and read docs/device-probing.md. Needs Chrome or Edge — Safari and Firefox have no WebMIDI — and will ask for SysEx permission, which is the whole point: without it every request is silently dropped and the device looks like it is not answering.
